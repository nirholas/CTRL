# Getting started with CTRL

CTRL is a web system designed for any modern device with a browser. CTRL apps can perform complex tasks more easily than native apps by simulating an abstract virtual system within the browser.

## Install

```bash
git clone https://github.com/nirholas/CTRL.git
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/CTRL.git
cd CTRL
```
